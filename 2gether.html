Site Reliability Engineer @ 2gether

2gether was a challenger bank offering cryptocurrency and fiat financial services. As part of the SRE team, I maintained the reliability and scalability of a multi-service AWS infrastructure supporting real-time financial operations for a growing user base.

My Role & Responsibilities
  • Managed multi-environment AWS infrastructure across development, staging, and production
  • Operated and scaled EKS clusters running containerized microservices
  • Administered PostgreSQL databases on RDS and DynamoDB for non-relational workloads
  • Configured and maintained messaging brokers: RabbitMQ (Amazon MQ) and Kafka (MSK)
  • Built monitoring dashboards and business and technical alerts in Datadog
  • Maintained CI/CD pipelines in Jenkins across multiple microservices
  • Managed infrastructure as code, versioned in Git repositories
  • Identified and executed optimizations that reduced operational costs
Tech Stack

AWS (EKS, RDS, DynamoDB, Amazon MQ, MSK) · Kubernetes · Jenkins · Datadog · PostgreSQL · RabbitMQ · Kafka · Terraform

Key Outcomes

Maintained high platform availability for a regulated financial product while continuously improving infrastructure reliability and reducing cloud spend through systematic optimization.
